5.7. CUDA C++ 메모리 모델

표준 C++는 스레드를 동기화하는 비용이 균일하고 낮다는 관점을 제시합니다.

CUDA C++는 다릅니다. 스레드를 동기화하는 비용은 스레드 간 거리가 멀어질수록 증가합니다. 블록 내 스레드 전반에서는 낮지만, 여러 GPU 및 CPU에서 실행되는 시스템 내 임의의 스레드 전반에서는 높습니다.

항상 낮지만은 않은 비균일한 스레드 동기화 비용을 고려하기 위해, CUDA C++는 cuda:: 네임스페이스의 표준 C++ 메모리 모델과 동시성 기능을 스레드 스코프로 확장하며, 기본적으로 표준 C++의 구문과 의미론을 유지합니다.

5.7.1. 스레드 스코프#

스레드 스코프는 cuda::atomic 또는 cuda::barrier 같은 동기화 프리미티브를 사용하여 서로 동기화할 수 있는 스레드의 종류를 지정합니다.

namespace cuda {

enum thread_scope {
  thread_scope_system,
  thread_scope_device,
  thread_scope_block,
  thread_scope_thread
};

}  // namespace cuda

5.7.1.1. 스코프 관계#

각 프로그램 스레드는 하나 이상의 스레드 스코프 관계에 의해 다른 각 프로그램 스레드와 연관됩니다:

  • 시스템의 각 스레드는 시스템(system) 스레드 스코프에 의해 시스템의 다른 각 스레드와 연관됩니다: cuda::thread_scope_system.

  • 각 GPU 스레드는 동일한 CUDA 디바이스 내에서 그리고 동일한 메모리 동기화 도메인 내에서 디바이스(device) 스레드 스코프에 의해 동일한 CUDA 디바이스의 다른 각 GPU 스레드와 연관됩니다: cuda::thread_scope_device.

  • 각 GPU 스레드는 블록(block) 스레드 스코프에 의해 동일한 CUDA 스레드 블록의 다른 각 GPU 스레드와 연관됩니다: cuda::thread_scope_block.

  • 각 스레드는 스레드(thread) 스레드 스코프에 의해 자기 자신과 연관됩니다: cuda::thread_scope_thread.

5.7.2. 동기화 프리미티브#

네임스페이스의 타입 std:: 및 cuda::std:: 네임스페이스의 해당 타입과 동일한 동작을 합니다 cuda:: 스코프가 다음과 같이 인스턴스화될 때 cuda::thread_scope_system.

5.7.3. 원자성#

원자적 연산은 다음 조건을 만족하는 경우, 지정한 스코프에서 원자적입니다:

  • 이는 다른 범위(scope)를 지정합니다. cuda::thread_scope_system, 또는

  • 스코프는 cuda::thread_scope_system 및:

    • 시스템 할당 메모리에 있는 객체에 영향을 미치고 pageableMemoryAccess가 1 [0]인 경우, 또는

    • 관리 메모리에 있는 객체에 영향을 미치고 concurrentManagedAccess가 1인 경우, 또는

    • 매핑된 메모리에 있는 객체에 영향을 미치고 hostNativeAtomicSupported가 1인 경우, 또는

    • 이는 다음 크기의 자연스럽게 정렬된 객체에 영향을 미치는 로드 또는 스토어입니다. 1, 2, 4, 8, 또는 16 의 바이트 매핑된 메모리 [1], 또는

    • GPU 메모리에 있는 객체에 영향을 미치며, GPU 스레드만이 이에 접근하고, 및

      • cudaDeviceGetP2PAttribute (&val, cudaDevP2PAttrNativeAtomicSupported, srcDev, dstDev) 각 접근하는 srcDev와 객체가 상주하는 GPU 사이에서, dstDev는 1이며, 또는

      • 단일 GPU의 GPU 스레드만이 이를 동시에 접근합니다.

참고

  • [0] PageableMemoryAccessUsesHostPagetables가 0이면 메모리 매핑 파일 또는 hugetlbfs 할당에 대한 원자적 연산은 원자적이지 않습니다.

  • [1] hostNativeAtomicSupported가 0이면, 시스템 할당 메모리 또는 매핑된 메모리 내 자연스럽게 정렬된 16바이트 폭 객체에 영향을 미치는 시스템 스코프에서의 원자적 로드 또는 저장 연산은 시스템 지원을 필요로 합니다. NVIDIA는 이러한 지원이 없는 시스템을 알고 있지 않으며, 그러한 시스템을 감지할 수 있는 CUDA API 쿼리도 제공되지 않습니다.

시스템 할당 메모리, 관리 메모리, 매핑된 메모리, CPU 메모리 및 GPU 메모리에 대한 자세한 내용은 이 가이드의 관련 섹션을 참조하십시오.

5.7.4. 데이터 레이스#

ISO/IEC IS 14882(C++ 표준)의 intro.races 21항을 다음과 같이 수정합니다:

ISO/IEC IS 14882(C++ 표준)의 atomics.fences 2항부터 4항까지를 다음과 같이 수정합니다:

릴리스 펜스 A는, 둘 다 어떤 원자 객체 M에서 동작하는 원자적 연산 X와 Y가 존재하여 A가 X보다 먼저 순서화되고, X가 M을 수정하며, Y가 B보다 먼저 순서화되고, Y가 X가 기록한 값 또는 X가 릴리스 연산이었다면 X가 머리가 되었을 가상의 릴리스 시퀀스에서 어떤 부수 효과에 의해 기록된 값을 읽는 경우, 어콰이어 펜스 B와 동기화됩니다. 그리고 각 연산(A, B, X, Y)은 서로의 연산을 수행한 스레드를 포함하는 스코프를 지정합니다.

릴리스 펜스 A는, 원자 객체 M에서 어콰이어 연산을 수행하는 원자적 연산 B와 동기화됩니다. 이는 A가 X보다 먼저 순서화되고, X가 M을 수정하며, B가 X가 기록한 값 또는 X가 릴리스 연산이었다면 X가 머리가 되었을 가상의 릴리스 시퀀스에서 어떤 부수 효과에 의해 기록된 값을 읽는 그러한 원자적 연산 X가 존재하는 경우이며, 각 연산(A, B, X)은 서로의 연산을 수행한 스레드를 포함하는 스코프를 지정합니다.

원자 객체 M에서 릴리스 연산인 원자적 연산 A는, M에서의 어떤 원자적 연산 X가 존재하여 X가 B보다 먼저 순서화되고 A가 기록한 값 또는 A가 머리인 릴리스 시퀀스에서 어떤 부수 효과에 의해 기록된 값을 읽는 경우, 어콰이어 펜스 B와 동기화됩니다. 그리고 각 연산(A, B, X)은 서로의 연산을 수행한 스레드를 포함하는 스코프를 지정합니다.

5.7.5. 예: 메시지 패싱#

다음 예제는 저장된 메시지를 x 변수는 블록 내 스레드에 의해 0 블록 내 스레드로 1 플래그를 통해 f:

초기에는

 
int x = 0, f = 0;

스레드 0 블록 0

 
x = 42;
cuda::atomic_ref<int, cuda::thread_scope_device> flag(f);
flag.store(1, memory_order_release);

스레드 0 블록 1

 
cuda::atomic_ref<int, cuda::thread_scope_device> flag(f);
while(flag.load(memory_order_acquire) != 1);
assert(x == 42);

다음은 이전 예제를 변형한 것으로, 두 스레드가 동기화 없이 f 객체에 동시에 접근하여 데이터 레이스가 발생하고, 정의되지 않은 동작을 보입니다:

초기 상태

 
int x = 0, f = 0;

스레드 0 블록 0

 
x = 42;
cuda::atomic_ref<int, cuda::thread_scope_block> flag(f);
flag.store(1, memory_order_release); // UB: data race

스레드 0 블록 1

 
cuda::atomic_ref<int, cuda::thread_scope_device> flag(f);
while(flag.load(memory_order_acquire) != 1); // UB: data race
assert(x == 42);

f에 대한 메모리 연산(저장 및 로드)은 원자적이지만, 저장 연산의 스코프는 “블록 스코프”입니다. 저장은 블록 0의 스레드 0에 의해 수행되므로, 블록 0의 다른 모든 스레드만 포함합니다. 그러나 로드를 수행하는 스레드는 블록 1에 있으며, 즉 블록 0에서 수행된 저장 연산이 포함하는 스코프에 속하지 않으므로, 저장과 로드가 “원자적”이 되지 않고 데이터 레이스를 유발합니다.

더 많은 예시는 PTX 메모리 일관성 모델 리트머스 테스트를 참조하십시오.
