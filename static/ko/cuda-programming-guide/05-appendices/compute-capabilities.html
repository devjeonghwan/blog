5.1. 컴퓨트 기능

컴퓨트 디바이스의 일반 사양과 기능은 컴퓨트 기능에 따라 달라집니다( Compute Capability and Streaming Multiprocessor Versions 참조).

표 29, 표 30, 그리고 표 31은 현재 지원되는 각 컴퓨트 기능과 연관된 기능 및 기술 사양을 보여줍니다.

모든 NVIDIA GPU 아키텍처는 리틀 엔디언 표현을 사용합니다.

5.1.1. GPU 컴퓨트 기능 가져오기#

CUDA GPU 컴퓨트 기능 페이지는 NVIDIA GPU 모델과 해당 컴퓨트 기능 간의 포괄적인 매핑을 제공합니다.

또는 NVIDIA Driver와 함께 제공되는 nvidia-smi 도구를 사용하여 GPU의 컴퓨트 기능을 얻을 수 있습니다. 예를 들어, 다음 명령은 시스템에서 사용 가능한 GPU 이름과 컴퓨트 기능을 출력합니다:

nvidia-smi --query-gpu=name,compute_cap

런타임에 컴퓨트 기능은 CUDA Runtime API cudaDeviceGetAttribute() , CUDA Driver API cuDeviceGetAttribute(), 또는 NVML API nvmlDeviceGetCudaComputeCapability()를 사용하여 얻을 수 있습니다:

#include <cuda_runtime_api.h>

int computeCapabilityMajor, computeCapabilityMinor;
cudaDeviceGetAttribute(&computeCapabilityMajor, cudaDevAttrComputeCapabilityMajor, device_id);
cudaDeviceGetAttribute(&computeCapabilityMinor, cudaDevAttrComputeCapabilityMinor, device_id);

#include <cuda.h>

int computeCapabilityMajor, computeCapabilityMinor;
cuDeviceGetAttribute(&computeCapabilityMajor, CU_DEVICE_ATTRIBUTE_COMPUTE_CAPABILITY_MAJOR, device_id);
cuDeviceGetAttribute(&computeCapabilityMinor, CU_DEVICE_ATTRIBUTE_COMPUTE_CAPABILITY_MINOR, device_id);

#include <nvml.h> // required linking with -lnvidia-ml

int computeCapabilityMajor, computeCapabilityMinor;
nvmlDeviceGetCudaComputeCapability(nvmlDevice, &computeCapabilityMajor, &computeCapabilityMinor);

5.1.2. 기능 가용성#

컴퓨트 아키텍처와 함께 도입된 대부분의 컴퓨트 기능은 이후의 모든 아키텍처에서 사용 가능하도록 의도됩니다. 이는 기능이 도입된 이후의 컴퓨트 기능에서 해당 기능의 가용성을 나타내는 “yes”로 표 29에 표시되어 있습니다.

5.1.2.1. 아키텍처별 기능#

컴퓨트 기능 9.0 디바이스부터, 아키텍처와 함께 도입되는 특화 컴퓨트 기능은 이후의 모든 컴퓨트 기능에서 사용 가능함이 보장되지 않을 수 있습니다. 이러한 기능을 아키텍처별(architecture-specific) 기능이라고 하며, 모든 클래스의 컴퓨트 기능을 대상으로 의도되지 않았거나 미래 세대에서 크게 변경될 수 있는 Tensor Core 연산과 같은 특화 연산의 가속을 목표로 합니다. 아키텍처별 기능을 활성화하려면 코드를 아키텍처별 컴파일러 타겟으로 컴파일해야 합니다(기능 세트 컴파일러 타겟 참조). 아키텍처별 컴파일러 타겟으로 컴파일된 코드는 컴파일된 정확한 컴퓨트 기능에서만 실행할 수 있습니다.

5.1.2.2. 패밀리별 기능#

컴퓨트 기능 10.0 디바이스부터, 일부 아키텍처별 기능은 둘 이상의 컴퓨트 기능을 가진 디바이스에서 공통입니다. 이러한 기능을 포함하는 디바이스는 동일한 패밀리에 속하며, 이러한 기능을 패밀리별(family-specific) 기능이라고도 부를 수 있습니다. 패밀리별 기능은 동일한 패밀리 내의 모든 디바이스에서 사용 가능함이 보장됩니다. 패밀리별 기능을 활성화하려면 패밀리별 컴파일러 타겟이 필요합니다. 섹션 5.1.2.3을 참조하십시오. 패밀리별 타겟으로 컴파일된 코드는 해당 패밀리의 멤버인 GPU에서만 실행할 수 있습니다.

5.1.2.3. 기능 세트 컴파일러 타겟#

컴파일러가 타겟으로 삼을 수 있는 컴퓨트 기능 세트는 세 가지입니다:

기준 기능 세트(Baseline Feature Set): 이후 컴퓨트 아키텍처에서도 사용 가능하도록 의도되어 도입된, 지배적인 컴퓨트 기능 세트. 이러한 기능과 가용성은 표 29에 요약되어 있습니다.

아키텍처별 기능 세트(Architecture-Specific Feature Set): 이후 컴퓨트 아키텍처에서 사용 가능함이 보장되지 않거나 크게 변경될 수 있는, 특화 연산을 가속하기 위해 도입된 아키텍처별이라 불리는 소규모의 고도로 특화된 기능 세트. 이러한 기능은 해당 “Compute Capability #.#” 하위 섹션에 요약되어 있습니다. 아키텍처별 기능 세트는 패밀리별 기능 세트의 상위 집합(superset)입니다. 아키텍처별 컴파일러 타겟은 Compute Capability 9.0 디바이스와 함께 도입되었으며, 컴파일 타겟에서 a 접미사를 사용하여 선택합니다. 예를 들어 컴퓨트 타겟으로 compute_100a 또는 compute_120a를 지정합니다.

패밀리별 기능 세트(Family-Specific Feature Set): 일부 아키텍처별 기능은 둘 이상의 컴퓨트 기능을 가진 GPU에서 공통입니다. 이러한 기능은 해당 “Compute Capability #.#” 하위 섹션에 요약되어 있습니다. 몇 가지 예외를 제외하면, 동일한 메이저 컴퓨트 기능을 가진 후세대 디바이스는 동일한 패밀리에 속합니다. 표 28은 예외를 포함하여, 디바이스 컴퓨트 기능과 패밀리별 타겟의 호환성을 나타냅니다. 패밀리별 기능 세트는 기준 기능 세트의 상위 집합(superset)입니다. 패밀리별 컴파일러 타겟은 Compute Capability 10.0 디바이스와 함께 도입되었으며, 컴파일 타겟에서 f 접미사를 사용하여 선택합니다. 예를 들어 컴퓨트 타겟으로 compute_100f 또는 compute_120f를 지정합니다.

컴퓨트 기능 9.0부터 시작하는 모든 디바이스는 아키텍처별인 기능 세트를 갖습니다. 특정 GPU에서 이러한 기능의 전체 세트를 활용하려면, 접미사 a가 붙은 아키텍처별 컴파일러 타겟을 사용해야 합니다. 또한 컴퓨트 기능 10.0부터는 서로 다른 마이너 컴퓨트 기능을 가진 여러 디바이스에 나타나는 기능 세트가 존재합니다. 이러한 명령어 세트를 패밀리별 기능이라고 하며, 이러한 기능을 공유하는 디바이스는 동일한 패밀리에 속한다고 말합니다. 패밀리별 기능은 해당 GPU 패밀리의 모든 멤버가 공유하는 아키텍처별 기능의 부분 집합(subset)입니다. 접미사 f가 붙은 패밀리별 컴파일러 타겟은 컴파일러가 이 공통 아키텍처별 기능 부분 집합을 사용하는 코드를 생성할 수 있도록 합니다.

예:

  • compute_100 컴파일 타겟은 아키텍처별 기능의 사용을 허용하지 않습니다. 이 타겟은 컴퓨트 기능 10.0 및 이후의 모든 디바이스와 호환됩니다.

  • compute_100f 패밀리별(family-specific) 컴파일 타겟은 GPU 패밀리 전반에서 공통인 아키텍처별 기능의 부분 집합을 사용할 수 있게 합니다. 이 타겟은 GPU 패밀리의 일부인 디바이스와만 호환됩니다. 이 예에서는 Compute Capability 10.0 및 Compute Capability 10.3 디바이스와 호환됩니다. 패밀리별 compute_100f 타겟에서 사용 가능한 기능은 기준 compute_100 타겟에서 사용 가능한 기능의 상위 집합(superset)입니다.

  • compute_100a 아키텍처별(architecture-specific) 컴파일 타겟은 Compute Capability 10.0 디바이스의 아키텍처별 기능 전체 세트를 사용할 수 있게 합니다. 이 타겟은 Compute Capability 10.0 디바이스와만 호환되며 그 외에는 호환되지 않습니다. compute_100a 타겟에서 사용 가능한 기능은 compute_100f 타겟에서 사용 가능한 기능의 상위 집합(superset)을 이룹니다.
