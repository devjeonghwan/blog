CUDA 프로그래밍 가이드

CUDA 및 CUDA 프로그래밍 가이드

CUDA는 GPU의 성능을 활용하여 컴퓨팅 성능을 획기적으로 향상시키는 NVIDIA에서 개발한 병렬 컴퓨팅 플랫폼 및 프로그래밍 모델입니다. 개발자는 이를 통해 연산 집약적인 애플리케이션을 가속할 수 있으며, 딥러닝, 과학 컴퓨팅, 고성능 컴퓨팅(HPC) 등의 분야에서 널리 사용됩니다.

이 CUDA 프로그래밍 가이드는 CUDA 프로그래밍 모델과 CUDA 플랫폼을 사용하여 GPU에서 실행되는 코드를 작성하는 방법에 대한 공식적이고 포괄적인 자료입니다. 이 가이드는 CUDA 프로그래밍 모델과 CUDA 플랫폼부터 언어 확장에 대한 세부 사항까지 모든 내용을 다루며, 특정 하드웨어 및 소프트웨어 기능을 활용하는 방법을 설명합니다. 또한 CUDA가 처음인 개발자가 CUDA를 학습할 수 있는 경로를 제공하며, CUDA를 사용해 애플리케이션을 구축하는 개발자에게 필수적인 자료를 제공합니다.

이 가이드의 구성

주로 라이브러리, 프레임워크 또는 DSL을 사용하는 개발자에게도 CUDA 프로그래밍 모델과 GPU가 코드를 실행하는 방식에 대한 이해는 추상화 계층 뒤에서 무엇이 일어나는지를 파악하는 데 가치가 있습니다. 이 가이드는 특정 프로그래밍 언어와 무관하게 CUDA가 어떻게 동작하는지 이해하려는 누구에게나(개발자가 아닌 사람에게도) 적용 가능한 CUDA 프로그래밍 모델에 대한 장으로 시작합니다.

이 가이드는 다섯 개의 주요 파트로 구성되어 있습니다:

  • 파트 1: 소개 및 프로그래밍 모델 개요

    • CUDA 프로그래밍 모델에 대한 언어 독립적인 개요와 CUDA 플랫폼에 대한 간단한 둘러보기.

    • 이 섹션은 개발자가 아니더라도 GPU와 GPU에서 코드를 실행하는 개념을 이해하려는 모든 사람이 읽도록 작성되었습니다.

  • 파트 2: CUDA에서의 GPU 프로그래밍

    • CUDA C++를 사용한 GPU 프로그래밍의 기초.

    • 이 섹션은 GPU 프로그래밍을 시작하려는 모든 사람이 읽도록 작성되었습니다.

    • 이 섹션은 완전한 설명이 아니라 학습용이며, 몇 가지 일반적인 성능 고려 사항을 포함해 CUDA 프로그래밍에서 가장 중요하고 흔히 사용되는 부분을 가르칩니다.

  • 파트 3: 고급 CUDA

    • 단일 애플리케이션에서 여러 GPU를 사용하는 것을 포함하여, 미세한 제어를 가능하게 하고 성능을 극대화할 기회를 더 많이 제공하는 CUDA의 더 고급 기능을 소개합니다.

    • 이 섹션은 각 기능이 언제, 왜 유용한지에 따라 정렬하여 각 기능의 목적과 기능을 간단히 소개하는 파트 4에서 다루는 기능 둘러보기로 마무리됩니다.

  • 파트 4: CUDA 기능

    • 이 섹션에는 CUDA 그래프, 동적 병렬 처리, 그래픽 API와의 상호운용성, 통합 메모리 등 특정 CUDA 기능에 대한 완전한 설명이 포함되어 있습니다.

    • 특정 CUDA 기능의 전체 그림을 아는 것이 필요할 때 이 섹션을 참고해야 합니다. 가능한 경우, 이 섹션에서 다루는 기능을 앞선 섹션에서 소개하고 동기를 부여하도록 주의를 기울였습니다.

  • 파트 5: 기술 부록

    • 기술 부록은 CUDA의 C++ 고수준 언어 지원, 하드웨어별 사양 및 기타 기술 사양에 대한 일부 레퍼런스 문서를 제공합니다.

    • 이 섹션은 CUDA 요소의 구문, 의미론 및 기술적 동작에 대한 구체적인 설명을 위한 기술 참조로서 작성되었습니다.

파트 1-3은 CUDA를 처음 접하는 개발자에게 안내형 학습 경험을 제공하지만, 어떤 경험 수준의 CUDA 개발자에게도 유용한 통찰과 최신 정보도 제공합니다.

파트 4와 5는 특정 기능과 상세 주제에 대한 풍부한 정보를 제공하며, CUDA 애플리케이션을 작성하면서 더 많은 세부 사항을 알아야 하는 개발자를 위해 선별되고 잘 구성된 참고 자료를 제공하는 것을 목표로 합니다.
