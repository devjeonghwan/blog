I added the Korean translation of the `CUDA Programming Guide` as a static document site inside the blog.

This document is based on the official [NVIDIA CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html), which I archived with a Python script and re-rendered into a new static site format for the blog.

Any content that required translation during that process was translated automatically with an LLM.
